# CCL Products (India) Ltd. - DCF Valuation Model

An independent discounted cash flow (DCF) valuation of **CCL Products
(India) Ltd.**, built using a five-year explicit forecast and the
perpetuity growth method.

**Valuation date:** 1 August 2025\
**Currency:** INR crore, unless otherwise stated\
**Method:** Unlevered Free Cash Flow (FCFF/UFCF) discounted at WACC

## Project Overview

This project demonstrates an integrated equity valuation workflow
covering:

-   Historical financial statement analysis
-   Revenue, margin and operating-driver forecasting
-   Unlevered free cash flow forecasting
-   Bottom-up beta and WACC estimation
-   Perpetuity-growth terminal value
-   Enterprise value to equity value bridge
-   WACC / terminal-growth sensitivity analysis
-   Base, best and worst case valuation outputs

## Model Structure

The model includes:

1.  Historical and forecast income statement
2.  Operating assumptions and forecast drivers
3.  Unlevered free cash flow schedule
4.  WACC calculation using peer-based bottom-up beta
5.  DCF schedule with partial-period discounting
6.  Terminal value using the Gordon Growth method
7.  Enterprise-to-equity value bridge
8.  Sensitivity tables for WACC and terminal growth
9.  Valuation dashboard

## Core Valuation Framework

The model uses:

`Enterprise Value = PV of Discrete Forecast UFCF + PV of Terminal Value`

Terminal value is estimated using:

`TV = FCFF(n+1) / (WACC - g)`

Equity value is derived as:

`Equity Value = Enterprise Value - Net Debt`

## Key Assumptions

-   Valuation date: 1 August 2025
-   Explicit forecast: FY2026-FY2030
-   Terminal growth rate: 3.50%
-   Terminal-year capital expenditure normalized toward depreciation
-   WACC derived from risk-free rate, equity risk premium, country risk
    premium, peer beta, cost of debt and target capital structure
-   Sensitivity analysis tests valuation across alternative WACC and
    terminal-growth assumptions


## Peer Set for Bottom-Up Beta

-   Vintage Coffee & Beverages Ltd.
-   Nestlé India Ltd.
-   Tata Consumer Products Ltd.

Five-year monthly regression betas are unlevered for peer capital
structures and then relevered to the target capital structure of CCL
Products.

## Dashboard

The dashboard summarizes:

-   Enterprise value
-   Equity value
-   Implied equity value per share
-   Current market price
-   Base / best / worst cases
-   WACC sensitivity
-   Terminal-growth sensitivity
-   Premium / discount to market price
